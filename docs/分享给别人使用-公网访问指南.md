# 分享给别人使用（公网访问指南）

> 目标：让**不在你身边、不同网络**的人（评委、同学、老师）都能打开这个演示站。
> 本文给出三种方式，**推荐第 1 种**——它不受你电脑开关机影响，二维码永久有效。

---

## 一、三种方式对比（先看这张表）

| | ① GitHub Pages（推荐） | ② Cloudflare 隧道 | ③ 局域网 |
|---|---|---|---|
| 别人要什么条件 | **任何网络、任何设备** | **任何网络、任何设备** | 必须和你同一 WiFi |
| 你电脑关机/睡眠 | ✅ **不影响** | ❌ 立刻断 | ❌ 立刻断 |
| 地址是否固定 | ✅ **永久固定** | ❌ 每次重启都变 | 变（换网络就变） |
| 二维码 | ✅ **可印在 PPT 上，永久有效** | ⚠️ 电脑开机才有效 | ⚠️ 仅现场 |
| 数据是否实时 | 构建时的快照 | 实时（连真实数据库） | 实时 |
| 管理后台 | ❌ 不含 | ✅ 含 | ✅ 含 |
| 成本 | 免费 | 免费 | 免费 |
| 适合场景 | **评委扫码、作品集展示、答辩** | 临时演示、需要后台 | 现场演示 |

**结论**：
- **给评委扫码 → 用 ①（GitHub Pages）**，一劳永逸
- **自己演示、要看管理后台 → 用 ② 或 ③**

### 它为什么能"没有后端也能用"

因为构建时做了两件事：

1. **数据快照**：把商品、溯源批次与节点、知识库问答等导出成 `data/api-snapshot.json` 一起上传
2. **浏览器端 API**：前端内置一个 API 拦截层（`scripts/demo-api.js`），
   `fetch('/api/...')` 不再发到服务器，而是本地查快照并计算响应；
   AI 客服直接调用**与后端完全相同**的规则模块（`scripts/ai-rules.mjs`）

所以评委扫码后：商品能看、能加购、能下单、能支付、能拿到溯源码、能扫码验真、能问 AI 客服——
全部不依赖任何服务器。

### 与完整版的差异（页面里也会提示，不假装是真后端）

| 项目 | 静态演示站 | 完整版 |
|---|---|---|
| 商品/溯源/知识库数据 | 构建时快照 | 数据库实时 |
| 购物车/订单/会员 | 存在浏览器本地，刷新回到初始状态 | 持久化 |
| 管理后台 | 不包含 | 包含 |
| 溯源防伪 | 内容摘要比对（能演示"改了就报警"） | ECDSA 私钥验签 |
| AI 客服 | 同一套规则模块 | 同一套规则模块 |

### 之后怎么更新

改完代码 push 到 `main` 即可，Actions 会自动重新构建并部署（约 1-2 分钟）。
也可以在 Actions 页面手动触发：进入 `Deploy static demo to GitHub Pages` 工作流后，
右上角会出现 **Run workflow** 按钮（注意：只有进入**具体某个工作流**才会显示这个按钮，
在 Actions 首页看不到；本仓库已配置 push 自动触发，一般不需要手动点）。

### 如果哪天部署失败了

常见原因是 Pages 的 Source 被改动。检查 **Settings → Pages → Source** 是否为 **GitHub Actions**。
（GitHub 限制 `GITHUB_TOKEN` 不能代为开启 Pages 设置，所以首次必须手动选一次。）

## 三、方式 ②：Cloudflare 隧道（需要实时数据 / 管理后台时用）

```bash
# 终端 1：启动后端（ACCESS_KEY 可省略，省略则不要求口令）
cd chayaya/backend
ACCESS_KEY=你的口令 npm start

# 终端 2：建立公网隧道
cloudflared tunnel --url http://127.0.0.1:8788
# 终端会打印 https://xxxx-xxxx.trycloudflare.com —— 发给别人
```

**特性**：
- 地址**每次重启都会变**（快速隧道没有固定域名）
- 电脑关机/睡眠即断
- 二维码会**自动适配**：别人从公网地址访问，溯源二维码就指向公网域名（见 `deriveBaseUrl()`）
- 本机访问**免口令**，公网/局域网访问需口令

## 四、方式 ③：局域网（现场演示最快）

服务默认监听 `0.0.0.0`，启动时会打印局域网地址：

```
局域网访问（同一 WiFi 的手机 / 同学电脑可直接打开）：
  用户端  http://192.168.x.x:8788/
  管理后台 http://192.168.x.x:8788/admin.html
```

- 需要与电脑同一 WiFi
- 若被 Windows 防火墙拦截，在弹出的提示里勾选"允许访问"
- 无需口令（本机与局域网默认放行）

## 六、常见问题

**Q：Google/微信里打开 Pages 链接提示不安全或打不开？**
Pages 自带 HTTPS，一般不会。如果被微信拦截，点右上角「···」→「在浏览器打开」。

**Q：Pages 页面打开是空白/一直转圈？**
1. 确认 Actions 部署成功（Actions 页签是绿色勾）
2. 强刷一次（Ctrl+F5），旧缓存可能还在
3. 打开浏览器控制台看是否有 `数据快照加载失败` —— 说明 `data/api-snapshot.json` 没部署上

**Q：演示站的数据是我改代码之前的旧数据？**
是的，快照是构建时生成的。改完后 push，等 Actions 跑完再强刷。

**Q：评委下单了会真的产生订单吗？**
不会。演示模式下订单只存在**他自己的浏览器**里，刷新就回到初始状态（页面里有提示）。
真实订单只在完整版（方式 ②③）里产生。

**Q：能不能让别人在演示站里看到管理后台？**
不能，这是刻意设计的——避免演示站被误当作真实系统操作。要看后台请用方式 ② 或 ③。

**Q：隧道地址变了，之前发出去的怎么办？**
重新发新地址。想固定就用**命名隧道**（需要 Cloudflare 账号 + 自己的域名），
或者干脆用 Pages（地址永久固定）。
