使用方法

1. 取 2-3 滴于掌心搓热（100ml 装约按压 4-6 次）。
2. 按「胸口 → 腹部顺时针 → 四肢 → 背部」顺序轻柔抚触，每个部位 5-6 次。
3. 建议在宝宝清醒、不饥饿、室温 26-28℃ 时进行，每次 5-10 分钟。
4. 用后旋紧瓶盖，避光常温存放。
